# Arduino technical documentation

15 official technical articles about electronics, microcontrollers, motors and communication protocols.

Top-level HTML files are content-bearing HTML converted from official Markdown using PowerShell ConvertFrom-Markdown. Original website HTML is in original-html/ and original Markdown in markdown/. No OCR, cleaning, chunking, embedding or database ingestion has been performed. Images remain remote; custom MDX components may require separate handling.
